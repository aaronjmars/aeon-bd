# Week in Review: Aeon Stopped Caring Which LLM You Bring

*2026-06-15 — Weekly shipping update*

> Aeon went provider-agnostic and identity-configurable this week — bring any LLM key and it routes and fails over on its own, build a soul and a north-star from the dashboard — while outside builders shipped the first wave of ecosystem skill packs.

## What Shipped

### Bring any key — the LLM gateway routes and fails over on its own

The gateway stopped being pinned to one provider. Provider routing now resolves at run time from whichever secrets are actually set (#430 — +95/−36 across 15 files), so you drop in a key and Aeon picks the route. If a provider fails mid-run, the gateway cascades to the next one instead of dying (#435 — +79/−24). Four new gateways landed in one shot — OpenRouter, UsePod, Venice, Surplus (#409) — alongside RootAI Edge as an MCP catalog entry (#422) and automatic Bankr-key routing (#386). Sidecar providers got the rough edges sanded: requests normalized to plain OpenAI shape (#412), empty text blocks sanitized (#411), and a `VENICE_BASE_URL` override contributed by an outside dev (#460). The README now documents all seven providers and the failover cascade (#423, #436).

### Identity is configurable now — SOUL.md and STRATEGY.md builders

Aeon got two ways to define what it is and what it's for. The SOUL.md tab plus a `soul-builder` skill builds an operator's voice from an X handle, a name, or a few links (#448 — +1011/−8 across 12 files), and you can one-click-install real souls straight from the gallery (#449). On the other axis, STRATEGY.md became a north-star every skill reads before acting (#370), with a dashboard STRATEGY tab and a `strategy-builder` skill to author it (#451). The soul builder also learned to guard against conflating two different people's data (#452) — a real failure mode when you're scraping a public profile.

### Outside builders shipped the first ecosystem skill packs

The interesting commits this week weren't all Aaron's. `beamr-route` — pay-per-call inference over x402 with an onchain receipt — came from SahilParikh03 (#419, +154/−2). `CTRL`, on-chain automation on Base, came from daxaur (#353). Three skill-pack registries landed back-to-back: a 20-skill signa pack with spend mandates and x402 receipts (#355, vritra12), Mneme (#356, mnemedb), and Careful Finance (#357, Zorrot Chen). Hivra joined the ecosystem list (#450). This is the column that matters for the project's trajectory — external contributors building *on* Aeon, not just Aaron building Aeon.

## Fixes & Polish
- One-click "Connect with Claude Code" in Settings, so auth isn't a config-file chore (#433).
- MCP server secrets auto-resolve from `.mcp.json` — no workflow editing to add a server (#378).
- One-click Telegram instant-mode Worker plus a guided deploy card (#368, #404).
- Scheduler catch-up widened to 2h so trailing-minute slots stop getting silently dropped (#440), and a bug where reformatted multi-line skills were skipped is fixed (#439).
- `./notify -f` for reliable multi-line notifications, replacing the `$(cat …)` pattern that tripped the sandbox (#441).
- MiroShark shipped an offline-verifiable signal payload — `signed-result.json`, HMAC-SHA256 (#152) — and a `/api/activity.json` what-just-completed polling feed (#153).

## What's Nearly Here
BEAMR as a first-class LLM gateway is open and out of draft (#418) — the natural next entry after this week's gateway push.
