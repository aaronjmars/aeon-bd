# Week in Review: Packs Ship, Community Builds, MiroShark Goes Multilingual

*2026-06-22 — Weekly shipping update*

> Aeon launched a full skill-pack system with one-click community install while five external builders merged packs in the same week, and MiroShark shipped multilingual simulations and transparent run costs.

## What Shipped

### Pack system: browse, discover, and install community skill packs from the dashboard

The skill-pack infrastructure landed as a complete unit. `packs.config.json` divides skills into Core vs optional packs (#474, +823 lines across `PacksPanel.tsx`, `packs/route.ts`, and `generate-packs-json`). The dashboard sidebar now defaults to enabled skills only (#477); a new Packs tab lets operators browse by category and flip packs on per-skill (#478, #479). One-click install from the PacksPanel triggers the new `install-skill` skill, which opens a PR and auto-merges it without human intervention (#483, #485). Installed community skills get a permanent "Installed" slot in the sidebar roster (#486). A `scripts/validate-pack.sh` pre-flight validator (#495) lets contributors test a pack locally before opening a PR. Five external builders shipped packs the same week the system launched.

### Community built in public: five packs, seven ecosystem additions

The PRs that landed from outside were the week's strongest signal. Charon (workflow preflight policy enforcement that runs before the selected skill reaches Claude, #511 from CharonAI-code), ClawHunter skills (#498), Simmer's Polymarket Trader (#499), Hunch Prediction Markets (#472 from Raj Karia), and Logbook (signed hash-chained action receipts, #507 from logbookbase) all merged. On the MCP catalog side, Glim.sh (live-data MCP with x402+MPP payments, #470 from Misha Kolesnik) and Litebeam (AI microservice routing with per-call x402 settlement, #508) landed as Featured entries. ECOSYSTEM.md grew by five more: ClawHunter, Glim.sh, Lens, LiteBeam, and Simmer (#528). The week's meaningful pattern: builders are shipping *on* Aeon, not just watching it.

### MiroShark: multilingual simulations and queryable run cost

MiroShark shipped full i18n infrastructure this week. Locale helpers were generalized to support any language and wired through the backend (#184); French prompts fully translated with a CI coverage gate that catches untranslated strings before merge (#186); German frontend copy and agent descriptions merged from community contributor Daniel Andersen (#189, #194, #178). The report agent now pulls locale-aware prompts from a registry with English as a constant fallback (#194). In parallel, cost became visible and queryable: `GET /api/simulation/<id>/cost.json` exposes a per-sim cost breakdown (#179), and public simulation embeds now show the estimated run cost upfront (#190). SearXNG and Firecrawl landed as websearch/scrape fallbacks (#178), making full simulations possible on non-OpenAI LLMs that lack native web search.

## Fixes & Polish
- `install-skill-pack` now regenerates `packs.json` on every install so newly added community skills aren't invisible in the roster (#487)
- Dashboard pack install forwards the `--path` flag correctly on install + copy command (#493)
- Forks start Core-only — enabled-packs are scoped to the repo, so a fork doesn't inherit the parent's installed packs (#491)
- Installed community skills render in the dashboard roster as a data-driven group (#490)
- MiroShark: suggest-scenarios timeout and token limit raised for non-English and local LLMs (#188)
- MiroShark: truncated `suggest_scenarios` JSON is now salvaged rather than failing the run (#192)
