## what shipped

### aeon — v0.1.0 + architecture cleanup

the window was dominated by the first stable release. 23 merged PRs across docs, features, and fixes.

**the big ones:**

**v0.1.0 stable release** (PRs #695–#712 + release thread)  
first stable. 70+ partner integrations baked in. the thread:
- multi-harness support: Grok and more, not just Claude
- improved channels: Instant mode in Telegram, new commands, email
- Open Knowledge Format support (by Google)
- skill attestation — prove what you've run, onchain or offchain
- observability opt-in via Langfuse
- global codebase simplification: fewer skills, fewer dependencies

[github.com/aaronjmars/aeon/releases/tag/v0.1.0](https://github.com/aaronjmars/aeon/releases/tag/v0.1.0)

**feat: retire postprocess; run in-run** (#707 + #695)  
killed the old `.pending-{service}/` + `scripts/postprocess-*.sh` deferred pattern. deploys, token transfers, any irreversible side-effect now runs in-run via `secretcurl`, fail-closed. cleaner failure surface — the run itself tells you if it broke, not a detached step nobody watches.

**x login live** (announced 07-10)  
log in with X → run autonomous agents on your X subscription for free. X Search natively wired. no separate API key. this is the compute→money arbitrage angle made accessible.

**fix(skills): route transient writes to /tmp** (#713)  
skill-generated scratch files no longer pollute the repo root. small but important hygiene.

**fix(scorer): empty_output flag tightened** (#714)  
the health scorer was flagging legitimate no-op runs as empty. now only triggers on empty FINAL output, not deliberate skips.

**fix: surface swallowed errors in MCP CLI + outputs route** (#716)  
error visibility in the MCP layer was broken — errors were swallowed silently. now they propagate.

**optimize: repo cleanup (8 dimensions)** (#715)  
dead code, type looseness, recursion bug in `parseContentsList`, shared app/script logic deduplicated. 8 categories of cleanup in one PR.

**AgentLink community pack registered** (#686)  
`techdigger/aeon-skill-pack-agentlink` — new community skill pack listed in the catalog.

**README halved** (#708)  
733 → 596 lines. Advanced internals moved to `docs/`. the README now sells, not documents.
