## What Shipped

### Attestation — every run is now provably real

PRs #650–653 wired Sigstore provenance into the aeon workflow. Every skill execution gets a GitHub-signed, publicly-logged manifest: what ran, when, what commit, what the output hash was. Immutable snapshot, cryptographically attested, logged to Rekor.

Why it matters: once a run is provably real, you can pay agents for verified work, gate on-chain actions behind proof-of-execution, let fleets trust each other without a human in the loop. The launch post got 43 likes, 6 reposts, 2,731 views.

### secretcurl — the sandbox myth is dead

PRs #684–695 retired every prefetch and postprocess script. Skills now call auth'd APIs (xAI/Grok, CoinGecko, Alchemy, Etherscan) directly in-run via `./secretcurl`. Auth headers never land in argv; the key is consumed inside the script. What was a multi-step workaround (write to `.pending-/`, let the postprocess shell pick it up) is now a single in-run call.

PR #696 wired `validate-config` into CI and removed 2 dead scripts. PR #685 deleted the dead `prefetch-xai.sh`. The architecture is cleaner across the board.

### aeon CLI

PR #676 shipped a headless `aeon` CLI reusing the dashboard lib — read + write, all phases, no browser. PR #677 documented it in the README. Fork-and-run is now a single command.

### Dashboard overhaul — 20+ PRs

PRs #662–675 rewrote the dashboard's copy and UX from the ground up: clearer skill page (enable toggle, schedule status, visible var edit), renamed controls (Team→Skills, Hire→Add, Duty→Enabled/Disabled), more-visible template buttons, transparent bordered mini-buttons, Re-register flow fixed. It reads like a product now instead of a prototype.

### Scheduler hardening

PRs #642–645 tightened the scheduler: exact-slot debt model (catches up missed cron slots instead of skipping them), retry on failed dispatches, Issues-as-state backend wired, file state defaulted (best for fork-and-forget setups).

### Langfuse observability

PRs #636–640 added optional Langfuse tracing — every aeon run is now a session, every Claude call a trace inside it. Dashboard got a Langfuse region dropdown. Known gaps documented; decision against a cost-proxy sidecar recorded.

### Notify improvements

PR #680 migrated the email channel from SendGrid to Resend. PR #641 rendered skill output as Telegram HTML globally. The notify stack is cleaner.

### Skill restructure

PR #647 reorganized into 59 skills across 6 packs (category == pack, cleaner for the registry). PR #646 wired the Grok harness to cover `XAI_API_KEY` via built-in web search when no key is set.

### Vuln-scanner restored

PR #693 made the scan arm functional again — allowlist grant and a tool-staging step were missing. The security fleet is back online.

### MiroShark — Farcaster mini app

MiroShark launched on Farcaster (Jul 8). Simulate anything with dozens of agents, now live in the feed. 19 likes, 3 reposts on the launch post.

- **PR #658** — `security: fix chain-input script injection + arbitrary file read (GHSA-h9v2 / GHSA-cqvj)` — the marquee fix. Chain inputs weren't sanitized, allowing a crafted `var:` to inject shell commands or read arbitrary files. Closed.
- **PR #661** — `security(messages): nudge when Discord/Slack poll without an author allowlist (GHSA-252c F5)` — missing allowlist = any DM can trigger a skill run. The fix adds a hard warning.
